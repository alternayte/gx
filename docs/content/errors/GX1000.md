title: "GX1000: parse error"
description: "The parser found text that is not valid .gx."
section: Diagnostics
code: GX1000
---

## Cause

The parser found text that is not valid `.gx`. The message names the problem, for example an expression with no closing brace.

## Example

```gx title="ui/card/Card.gx"
package card

props {
  Title string
}

<article>{p.Title</article>
```

`gx check` reports:

```text title="gx check"
ui/card/Card.gx:8:1: GX1000: unclosed {
```

## Fix

1. Go to the line in the message.
2. Close the tag, the brace or the block that is open.
