---
title: "GX3001: pattern variable has no field"
description: "The route pattern has a variable and the route type has no field for it."
section: Diagnostics
code: GX3001
---

## Cause

The route pattern has a variable and the route type has no field for it. A variable binds to the field with the same name; upper and lower case are equal.

## Example

```go title="shop/route/route.go"
package route

import "github.com/alternayte/gx"

type Show struct {
	gx.Route `GET /products/{id}`
}
```

`gx check` reports:

```text title="gx check"
shop/route/route.go:5:6: GX3001: pattern variable "id" has no field in "Show"
```

## Fix

1. Add a field with the name of the variable.
2. Or add a `path:"name"` tag to the field that takes the value.
