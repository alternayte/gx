---
title: "GX2008: fragment free variable"
description: "A fragment uses a variable that is not one of its parameters."
section: Diagnostics
code: GX2008
---

## Cause

A fragment uses a variable that is not one of its parameters. The generated fragment function can use its parameters and `p` only.

## Example

```gx title="cart/Cart.gx"
package cart

props {
  Total int
}

<div>
  total := p.Total
  tax := total / 10
  <span #total(total int)>{total + tax}</span>
</div>
```

`gx check` reports:

```text title="gx check"
cart/Cart.gx:10:36: GX2008: undefined: tax
```

## Fix

1. Add the variable to the parameter list of the fragment.
2. Or calculate the value in the fragment from its parameters.
