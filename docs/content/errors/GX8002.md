---
title: "GX8002: component is not declared in this collection"
description: "A content file uses a component tag that is not in the Components list of its collection."
section: Diagnostics
code: GX8002
---

## Cause

A content file uses a component tag that is not in the `Components` list of its collection.

## Example

```markdown title="content/docs/start.md"
---
title: Start
---

# Start

<site.Note>Read this first.</site.Note>
```

```gx title="site/Note.gx"
package site

props {
  Children gx.Node
}

<aside>{p.Children}</aside>
```

```go title="site/site.go"
package site

import "github.com/alternayte/gx"

// Meta is the frontmatter of one page.
type Meta struct {
	Title string `yaml:"title"`
}

// Docs is the docs collection.
var Docs = gx.Collection[Meta]("content/docs")
```

`gx check` reports:

```text title="gx check"
content/docs/start.md:7:1: GX8002: component "Note" is not declared in this collection
```

## Fix

1. Add the component to the `Components` call of the collection.
2. Or remove the tag from the content file.
