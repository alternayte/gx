---
title: "GX8004: code file or line range is missing"
description: "gx.CodeFile names a file that does not exist, or a line range that is longer than the file."
section: Diagnostics
code: GX8004
---

## Cause

`gx.CodeFile` names a file that does not exist, or a line range that is longer than the file.

## Example

```gx title="ui/code/Code.gx"
package code

props {
  Code gx.Code
}

<pre>{p.Code.Source}</pre>
```

```gx title="ui/code/Page.gx"
package code

<Code code={gx.CodeFile("content/sample.go", "1-3")} />
```

`gx check` reports:

```text title="gx check"
ui/code/Page.gx:3:13: GX8004: gx.CodeFile cannot read content/sample.go
```

## Fix

1. Correct the path. The path starts at the module root.
2. Correct the line range.
