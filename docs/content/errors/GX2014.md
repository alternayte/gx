---
title: "GX2014: signal needs an initial value"
description: "A signal in the signals block has no first value."
section: Diagnostics
code: GX2014
---

## Cause

A signal in the `signals` block has no first value. The browser needs a value before the first event.

## Example

```gx title="cart/Cart.gx"
package cart

signals {
  Qty int
}

<p text={$Qty}></p>
```

`gx check` reports:

```text title="gx check"
cart/Cart.gx:4:3: GX2014: signal "Qty" needs an initial value
```

## Fix

Give the signal a first value, for example `Qty int = 1`.
