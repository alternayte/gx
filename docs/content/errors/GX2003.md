---
title: "GX2003: unknown attribute or slot"
description: "A component call passes an attribute that is not a prop of the component."
section: Diagnostics
code: GX2003
---

## Cause

A component call passes an attribute that is not a prop of the component. An attribute name is the prop name with a lower-case first letter.

## Example

```gx title="ui/card/Card.gx"
package card

props {
  Title string
}

<article>{p.Title}</article>
```

```gx title="ui/card/Page.gx"
package card

<Card title="News" tilte="Old" />
```

`gx check` reports:

```text title="gx check"
ui/card/Page.gx:3:20: GX2003: unknown attribute "tilte" on <Card>
```

## Fix

1. Correct the attribute name.
2. Or add the prop to the `props` block of the component.
