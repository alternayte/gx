---
title: "GX1002: generated code is missing or stale"
description: "A .gx file changed and its generated Go file did not."
section: Diagnostics
code: GX1002
---

## Cause

A `.gx` file changed and its generated Go file did not. The generated file is missing or has old content.

## Example

```gx title="ui/card/Card.gx"
package card

props {
  Title string
}

<article>{p.Title}</article>
```

The file `ui/card/Card_gx.go` does not exist.

`gx check` reports:

```text title="gx check"
gxdev_gallery/gallery_gx.go:1:1: GX1002: generated code is missing or stale; run gx generate
ui/card/Card.gx:1:1: GX1002: generated code is missing or stale; run gx generate
```

## Fix

1. Run `gx generate`.
2. Commit the generated files.
