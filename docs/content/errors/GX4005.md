---
title: "GX4005: call is not allowed in a client expression"
description: "A client expression calls a function that has no JavaScript form."
section: Diagnostics
code: GX4005
---

## Cause

A client expression calls a function that has no JavaScript form. A client expression can call the functions of package `gxc` only.

## Example

```gx title="cart/Cart.gx"
package cart

import "strings"

signals {
  Name string = ""
}

<p show={strings.Contains($Name, "a")}>Has an a</p>
```

`gx check` reports:

```text title="gx check"
cart/Cart.gx:9:10: GX4005: only gxc helpers are allowed in a client expression
```

## Fix

1. Use a `gxc` function when one does the work.
2. Or calculate the value on the server and pass it as a prop.
