---
title: "GX2001: missing required prop"
description: "A component call does not pass a prop that has no default."
section: Diagnostics
code: GX2001
---

## Cause

A component call does not pass a prop that has no default. A prop with no default is required.

## Example

```gx title="ui/card/Card.gx"
package card

props {
  Title string
}

<article>{p.Title}</article>
```

```gx title="ui/card/Page.gx"
package card

<Card />
```

`gx check` reports:

```text title="gx check"
ui/card/Page.gx:3:1: GX2001: missing required prop "Title" on <Card>
```

## Fix

1. Pass the prop at the call.
2. Or give the prop a default in the `props` block of the component.
