---
title: "GX3004: duplicate route pattern"
description: "Two route types have the same method and pattern."
section: Diagnostics
code: GX3004
---

## Cause

Two route types have the same method and pattern. The router can send a request to one of them only.

## Example

```go title="shop/route/route.go"
package route

import "github.com/alternayte/gx"

type Home struct {
	gx.Route `GET /shop`
}

type List struct {
	gx.Route `GET /shop`
}
```

`gx check` reports:

```text title="gx check"
shop/route/route.go:9:6: GX3004: pattern "GET /shop" is already used by "Home"
```

## Fix

1. Change the pattern of one route type.
2. Or remove one of the two types.
