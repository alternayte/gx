---
title: "GX2000: type error in an expression"
description: "A Go expression in a .gx file has a type error."
section: Diagnostics
code: GX2000
---

## Cause

A Go expression in a `.gx` file has a type error. The Go type checker gives the message.

## Example

```gx title="ui/card/Card.gx"
package card

props {
  Count int
}

<p>{p.Count + "items"}</p>
```

`gx check` reports:

```text title="gx check"
ui/card/Card.gx:7:5: GX2000: invalid operation: p.Count + "items" (mismatched types int and untyped string)
```

## Fix

Correct the expression. The position is the line and column in the `.gx` file.
