---
title: "GX6006: widget input field cannot be an attribute"
description: "A field of the route input of a widget has a type that an attribute of an element cannot hold."
section: Diagnostics
code: GX6006
---

## Cause

A field of the route input of a widget has a type that an attribute of an element cannot hold. The fields of the input are the attributes of the element. An attribute is text, so a field is a string, a number, a bool, or a named type of one of these.

## Example

```gx title="cart/Cart.gx"
package cart

props {
  Currency string
}

<section>
  <p>Your cart in {p.Currency}</p>
</section>
```

```go title="cart/route/route.go"
package route

import "github.com/alternayte/gx"

type Widget struct {
	gx.Route `GET /widgets/cart`
	Currency string   `query:"currency" default:"EUR"`
	Coupons  []string `query:"coupons"`
}
```

```go title="cart/cart.go"
package cart

import (
	"github.com/alternayte/gx"
	"app/cart/route"
)

var CartWidget = gx.Widget(func(c *gx.Ctx, in route.Widget) (CartProps, error) {
	return CartProps{Currency: in.Currency}, nil
}, Cart).Tag("acme-cart")

var Routes = gx.Collect(CartWidget)
```

`gx check` reports:

```text title="gx check"
cart/route/route.go:8:2: GX6006: field "Coupons" of the widget input "Widget" has the type []string; an attribute holds a string, a number or a bool
```

## Fix

1. Give the widget an id as an attribute, and load the list or the object in the loader of the widget.
2. For a small set of values, use a string type with constants.
