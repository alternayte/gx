---
title: "GX2006: duplicate slot"
description: "A component call fills one slot two times."
section: Diagnostics
code: GX2006
---

## Cause

A component call fills one slot two times.

## Example

```gx title="ui/card/Card.gx"
package card

props {
  Header   gx.Node = nil
  Children gx.Node
}

<article>
  <header>{p.Header}</header>
  {p.Children}
</article>
```

```gx title="ui/card/Page.gx"
package card

<Card>
  <:header>First</:header>
  <:header>Second</:header>
  Text
</Card>
```

`gx check` reports:

```text title="gx check"
ui/card/Page.gx:5:3: GX2006: slot "header" is given twice on <Card>
```

## Fix

1. Remove one of the two slot tags.
2. Or put the two parts in one slot tag.
