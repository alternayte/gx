---
title: "GX3006: route field has the name of a generated method"
description: "A route input field has the same name as a method that Gx generates for the route type."
section: Diagnostics
code: GX3006
---

## Cause

A route input field has the same name as a method that Gx generates for the route type. The generated file holds methods such as `Pattern`, `URL`, `Bind`, `GxFormValue` and `GxTool`. A field and a method cannot have the same name on one type, so the generated code does not compile.

## Example

```go title="shop/route/route.go"
package route

import "github.com/alternayte/gx"

type AddRSS struct {
	gx.Route `POST /sources/add`
	URL      string
}
```

`gx check` reports:

```text title="gx check"
shop/route/route.go:7:2: GX3006: field "URL" has the name of a method that gx generates for "AddRSS"
```

## Fix

1. Rename the field, for example to `Address`.
