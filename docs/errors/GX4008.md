# GX4008: signal-bound fields need rules or gx.Unchecked

## Cause

An action input has a field tagged `signal:"..."` and the input type declares
no `Rules()` method. The client controls every signal value (SI-13).

## Example

```
type Add struct {
	gx.Route `POST /add`
	Qty int `signal:"qty"`
}
```

with no `func (in *Add) Rules() gx.Rules`.

## Fix

Add `Rules()` for the signal fields, or embed `gx.Unchecked` when the value
needs no checks.
