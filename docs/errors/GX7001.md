# GX7001: conversion to gx.SafeHTML needs //gx:trusted

## Cause

A non-constant value is converted to `gx.SafeHTML` without a trust marker.

## Example

```go
banner := gx.SafeHTML(userInput)
```

## Fix

Mark the line as trusted, with the reason:

```go
banner := gx.SafeHTML(userInput) //gx:trusted escaped by sanitize.Comment
```

A constant string needs no marker.
