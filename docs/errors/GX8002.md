# GX8002: component is not declared in this collection

## Cause

A Markdown file uses a component tag that is not in the `Components(...)`
list of its `gx.Collection`.

## Example

```
<docs.Widget />
```

when the collection declares only `docs.Aside` and `docs.Steps`.

## Fix

Add the component to the collection:

```go
var Docs = gx.Collection[DocMeta]("content/docs").
  Components(docs.Aside, docs.Steps, docs.Widget)
```
