# GX4002: more than one action is registered for a route type

## Cause

Two or more `gx.Action` calls name the same route type. One route type has
exactly one handler (P2, one way). The compiler reports the error at each
invocation: an `on:` attribute or a `gx.ToastAction` call.

## Example

```
gx.Action(handleOne)  // input type AddToCart
gx.Action(handleTwo)  // input type AddToCart
```

## Fix

Delete all but one registration, or give the second handler its own route
type.
