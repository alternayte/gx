# GX4010: unknown event modifier or special event

## Cause

An `on:` attribute uses a modifier or special event that the adapter does not
have.

## Example

```
on:click.hover
on:interval
```

## Fix

Use one of `.prevent`, `.stop`, `.once`, `.outside`, `.window`,
`.debounce(300ms)`, `.throttle(1s)`, or the special events `load`, `visible`
and `interval(5s)`.
