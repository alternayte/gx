# GX4007: value or operator is not allowed in a client expression

## Cause

A client expression uses a value or operator without the same meaning in Go
and JavaScript. This covers `==` and `!=` on anything but bool, string and
numbers, and any other unsupported operand.

## Example

```
show={$Items == p.Items}
```

## Fix

Compare a bool, string or number, or compute the value on the server.
