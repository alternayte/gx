# GX4003: no signal is declared for a signal-bound field

## Cause

An action input field is tagged `signal:"name"` and the component that
invokes the action declares no signal with that name.

## Example

```go
type AddToCart struct {
	gx.Route `POST /cart/add`
	Qty int `signal:"qty"`
}
```

invoked from a component with no `signals { Qty int = 1 }` block.

## Fix

Declare the signal in the invoking component, or drop the `signal` tag.
