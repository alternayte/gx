# GX8004: code file or line range is missing

## Cause

A `gx.CodeFile` call or a docs kit `Code` block names a repository file, a
line range, or both, and the build cannot read them.

The compiler reads the file at build time. A code block never reads a file
at request time.

## Example

```gx
<docs.Code code={gx.CodeFile("content/docs/start.md", "1-40")} />
```

When `content/docs/start.md` does not exist, or holds fewer than 40 lines,
the build fails with GX8004.

## Fix

1. Correct the path. It is relative to the module root.
2. Correct the line range. Line numbers start at 1.
3. Add the file to the repository when it is missing.
