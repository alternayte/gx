# GX7002: gx.Secret cannot cross to the client

## Cause

A value of type `gx.Secret` reaches a client expression, a signal, an island
prop or a fragment sent to another user (SI-04).

## Example

```
signals { Token gx.Secret = "x" }
<p show={$Token}>x</p>
```

## Fix

Keep the secret on the server. Use `Reveal()` only in server code.
