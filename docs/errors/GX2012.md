# GX2012: signal instance needs a key

## Cause

A component with signals renders more than once without an instance key.
Two instances would share one signal namespace (REQ-ACT-06).

## Example

```
for _, it := range p.Items {
  <Cart start={it.Start} />
}
```

## Fix

Add `key={it.ID}` to the component, or set a key on an enclosing element.
