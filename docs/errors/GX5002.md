# GX5002: duplicate view-transition-name in one template

## Cause

Two elements in one template use the same transition value. A duplicate
`view-transition-name` makes the browser skip the transition.

## Example

```
<img transition={Hero(1)} src={a} />
<img transition={Hero(1)} src={b} />
```

## Fix

Give each element its own key:

```
<img transition={Hero(a.ID)} src={a} />
<img transition={Hero(b.ID)} src={b} />
```
