# GX8003: content link or anchor is broken

## Cause

A Markdown link in a content file points at a page or a heading that does
not exist.

`gx check` resolves internal links against the collection entries and their
headings. `gx check --external-links` also requests every `http` or `https`
link.

## Example

```markdown
[Setup](/missing/)
[Install](#install)
```

When no entry answers `/missing/`, or the page has no `install` heading,
the check reports GX8003.

## Fix

1. Correct the path or the anchor.
2. Add the page or heading when it is missing.
3. Run `gx routes` to list the known paths.
