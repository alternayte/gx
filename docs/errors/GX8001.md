# GX8001: frontmatter is malformed or unknown

## Cause

The YAML frontmatter of a content file does not parse, holds a field that
is not on the Meta type, or gives a value of the wrong kind.

## Example

```markdown
---
order: "first"
---

Text.
```

when `Meta.Order` is an `int`.

## Fix

Give the field the kind of the Meta type:

```markdown
---
order: 1
---
```
