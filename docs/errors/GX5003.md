# GX5003: class string is built at runtime

## Cause

A class value or a `gx.Cx` argument is built from a runtime value, for
example with `fmt.Sprintf` or `+`. Tailwind scans source text, so it never
sees this class.

## Example

```
<div class={fmt.Sprintf("p-%d", p.Size)}>
```

```go
gx.Cx("p-4", "mt-" + p.Margin)
```

## Fix

Use a static class, or map the value through `gx.Enum`:

```go
var size = gx.Enum[Size]{Sm: "p-2", Md: "p-4", Lg: "p-6"}
gx.Cx(size[p.Size])
```
