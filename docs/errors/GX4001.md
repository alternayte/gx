# GX4001: no action is registered for a route type

## Cause

An `on:` attribute or a `gx.ToastAction` call invokes a route type, and no
`gx.Action` call registers a handler for it.

## Example

```
on:click={AddToCart{ID: 1}}
```

or, in a Go file:

```
c.Toast("Removed", gx.ToastAction("Undo", AddToCart{ID: 1}))
```

with no `gx.Action(func(c *gx.Ctx, in AddToCart) error { ... })` in the
module.

## Fix

Add a `gx.Action` value for the route type, or correct the type name.
