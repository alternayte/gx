# GX3005: route package contents

## Cause

A package whose path ends in `route` holds code that is not a route type, or
it imports a package other than `gx` and the standard library.

## Example

```go
package route

import "app/products" // not allowed

type Show struct{ gx.Route `GET /products/{id}` }
```

## Fix

Keep only route structs in the route package. Move helpers and other types to
the slice package.
