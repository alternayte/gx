# GX4004: signal type does not match the action field

## Cause

A `signal:"name"` field has a different Go type than the signal declared in
the invoking component.

## Example

```go
signals { Qty string = "" }
```

with `Qty int ` + "`" + `signal:"qty"` + "`" + ` on the action input.

## Fix

Make the signal type and the field type equal.
