# GX3001: pattern variable has no field

## Cause

The route pattern has a `{name}` variable. The input struct has no field for it.

## Example

```go
type Show struct {
	gx.Route `GET /products/{id}`
	Code string
}
```

## Fix

Add the field `ID int64`, or add a `path:"id"` tag to the field that binds it.
