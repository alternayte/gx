# GX4009: action method cannot be invoked from the client

## Cause

An `on:` attribute invokes an action whose method is not GET, POST, PUT,
PATCH or DELETE. The hypermedia adapter has no client function for it.

## Example

```
type Ping struct { gx.Route `OPTIONS /ping` }
```

invoked from `on:click`.

## Fix

Use one of GET, POST, PUT, PATCH or DELETE, or call the route from ordinary
HTML.
