# GX4009: action method cannot be invoked from the client

## Cause

An `on:` attribute or a `gx.ToastAction` call invokes an action whose method
is not GET, POST, PUT, PATCH or DELETE. The hypermedia adapter has no client
call for it.

## Example

```
type Ping struct { gx.Route `OPTIONS /ping` }
```

invoked from `on:click` or from `gx.ToastAction`.

## Fix

Use one of GET, POST, PUT, PATCH or DELETE, or call the route from ordinary
HTML.
