# GX5001: gx.Enum misses a constant of its type

## Cause

A `gx.Enum[T]` map has no entry for a constant of `T`.

## Example

```go
type Variant string

const (
	Default Variant = "default"
	Raised  Variant = "raised"
)

var variant = gx.Enum[Variant]{Default: "border"} // Raised is missing
```

## Fix

Add an entry for every constant:

```go
var variant = gx.Enum[Variant]{
	Default: "border",
	Raised:  "border shadow-lg",
}
```
