# Skeleton

A placeholder while content loads.

## Usage

```gx
<skeleton.Skeleton class="h-4 w-40" />
```

## Do

- Match the size of the content that will replace it.
- Use two or three skeletons for a list.

## Don't

- Do not leave a skeleton on the page after the load finishes.
- Do not show a skeleton for longer than a moment.

## Keyboard

This component is static. It takes no focus and has no key bindings.
