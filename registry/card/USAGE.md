# Card

A bordered surface for grouped content.

## Usage

```gx
<card.Card title="Revenue" description="Last 30 days">
  <p>$12,400</p>
</card.Card>
```

## Do

- Use one card per unit of content.
- Use the `Footer` node for a card action.

## Don't

- Do not nest cards.
- Do not use a card for the whole page.

## Keyboard

This component is static. It takes no focus and has no key bindings.
